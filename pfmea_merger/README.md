# PFMEA Merger — ابزار تجمیع فایل‌های PFMEA در فرآیند APQP

یک برنامهٔ دسکتاپ ساده که به کمک آن می‌توانید چند فایل PFMEA (هرکدام مربوط به یک ایستگاه) را بارگذاری کنید، هر ایستگاه را که خواستید تیک بزنید و در نهایت یک فایل اکسل تجمیعی «با حفظ کامل فرمت اصلی» بگیرید.

---

## ✨ ویژگی‌ها

- 🖱 رابط کاربری دسکتاپ با **PyQt6** (تم دارک، دوزبانه فارسی/انگلیسی، RTL کامل)
- 📊 حفظ کامل فرمت (استایل، مرج سل، عرض ستون، ارتفاع ردیف، فونت و رنگ)
- 📁 بارگذاری از **پوشه**، **آپلود دستی** یا **Drag & Drop** روی پنجره
- ☑ نمایش نام ایستگاه‌ها (کد OPC + نام) و انتخاب دلخواه با چک‌باکس
- ↕ تغییر ترتیب ایستگاه‌ها با دکمه‌های بالا/پایین/بالاترین/پایین‌ترین
- 💾 **پروفایل محصول**: ترتیب ایستگاه‌ها، **وضعیت چک‌باکس هر ایستگاه**، مسیر قالب و تنظیمات را برای هر محصول ذخیره و بارگذاری کنید
- 🖱 راست‌کلیک روی جدول برای منوی سریع (حذف / تیک زدن / جابجایی)
- ⌨ میانبرهای کیبورد: Space برای تغییر تیک، Delete برای حذف انتخاب
- ⚙ تنظیمات کاملاً قابل تغییر (تعداد ردیف‌های سربرگ، ستون‌های OPC/نام، کلیدواژه‌های پاورقی و…)
- 📚 شیت `History` از قالب کپی می‌شود (بدون تولید داده جعلی)
- 🧵 پردازش در ترد جدا (UI منجمد نمی‌شود) + نوار پیشرفت
- 🔓 خطای واضح در صورت باز بودن فایل خروجی در اکسل
- 📄 باز کردن خودکار فایل خروجی پس از تجمیع (قابل غیرفعال کردن)

## 🚀 نصب و اجرا

```bash
# 1. نصب وابستگی‌ها
pip install -r pfmea_merger/requirements.txt

# 2. اجرا
python -m pfmea_merger.app
```

### تست هدلس (بدون UI)

```bash
# اول یک بار فایل‌های نمونه بسازید:
python -m pfmea_merger.tools.make_sample_inputs

# سپس تجمیع همه‌شان را تست کنید:
python -m pfmea_merger.tools.test_merge
# خروجی: pfmea_merger/output/Merged_TEST.xlsx
```

## 🧠 منطق کار برنامه

هر فایل PFMEA این ساختار را دارد:

| ردیف | محتوا |
|---|---|
| 1 تا 8 | سربرگ (لوگو، نام قطعه، نام تامین‌کننده، عناوین جدول…) |
| 9 تا … | ردیف‌های داده — هر ایستگاه از یک ردیف با کد OPC در ستون A شروع می‌شود و تا ردیف قبل از OPC بعدی ادامه دارد |
| … تا آخر | پاورقی (تهیه‌کنندگان، تایید کننده، توزیع نسخ…) |

برنامه:

1. یک فایل **Template** را به عنوان قالب می‌گیرد (سربرگ و پاورقی و استایل از این فایل).
2. هر فایل ورودی را باز می‌کند و ردیف‌های داده‌ای هر ایستگاه را استخراج می‌کند.
3. در فایل خروجی، **یک بار** سربرگ Template را می‌نویسد، سپس ردیف‌های داده هر ایستگاهِ انتخاب‌شده (به ترتیب دلخواه کاربر) را کپی می‌کند و در انتها **یک بار** پاورقی Template را می‌گذارد.

## ⚙ تنظیمات

از منوی ⚙ Settings می‌توانید این‌ها را عوض کنید:

| تنظیم | پیش‌فرض | توضیح |
|---|---|---|
| Header rows | 8 | تعداد ردیف‌های سربرگ |
| Data start row | 9 | ردیف شروع داده |
| OPC column | A | ستون کد OPC |
| Station name column | B | ستون نام ایستگاه |
| Sheet name | PFMEA | نام شیت اصلی |
| History sheet | History | نام شیت تاریخچه |
| Footer markers | تهیه کنندگان، تایید کننده، تصویب کننده، توزیع نسخ، علامت، بازنگری فرم، کد فرم | کلیدواژه‌هایی که برنامه با دیدنشان می‌فهمد پاورقی شروع شده |

## 💾 پروفایل محصول

برای هر محصول (مثلاً `SBM SOREN`) می‌توانید یک پروفایل بسازید که موارد زیر را نگهداری کند:

- مسیر فایل Template
- ترتیب دلخواه ایستگاه‌ها (بر اساس کد OPC)
- همهٔ تنظیمات (Header rows، ستون‌ها، …)

دفعهٔ بعد که همین محصول را بارگذاری کردید، فقط پروفایل را انتخاب و «بارگذاری» کنید و همه چیز آماده است.

پروفایل‌ها به‌صورت فایل JSON در پوشهٔ `pfmea_merger/profiles/` ذخیره می‌شوند.
